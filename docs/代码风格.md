# C# 代码风格

参照微软 [.NET 编码约定](https://learn.microsoft.com/en-us/dotnet/csharp/fundamentals/coding-style/coding-conventions) 和 [C# 格式选项](https://learn.microsoft.com/en-us/dotnet/fundamentals/code-analysis/style-rules/csharp-formatting-options)，项目根目录 `.editorconfig` 固化格式规则。

- C# 使用 4 空格缩进、Allman 大括号换行，控制语句保留大括号。
- 每条语句单独一行，统一运算符、参数及逗号间距。
- System using 优先，显式声明访问修饰符。
- 类型明显时使用 var，其他位置使用显式类型。
- 项目文件采用 2 空格缩进。

三个项目均移除 Nullable enable 配置；同步清理引用类型可空标注及空值抑制运算符，保留 decimal?、DateOnly?、Guid? 等可空值类型。未识别字段仍返回 null，功能语义保持不变。

可复现检查：

```powershell
dotnet format whitespace Invoice.Core.sln --no-restore --verify-no-changes
dotnet format style Invoice.Core.sln --no-restore --verify-no-changes --diagnostics IDE0011 IDE0007 IDE0008 IDE0040 --severity info
```
