# 发布与仓库职责

- 本仓库：`https://github.com/Mitzh/Invoice.Core`。
- 解决方案：`Invoice.Core.sln`。
- 根命名空间：`Mitzh.Invoice.Core`。
- NuGet 包：`Mitzh.Invoice.Core`，当前版本 3.0.0。
- `ci.yml` 在 main/PR 构建并运行本仓库检查，产物保存在 Actions。
- `publish-nuget.yml` 在推送 v* 标签或手动运行时检查、打包并发布一个包。
- NuGet Trusted Publishing 需限定 owner=Mitzh、repo=Invoice.Core、workflow=publish-nuget.yml、包名=Mitzh.Invoice.Core，仅授予新增包和版本发布权限。

`Directory.Build.props` 保存公共元数据。发布前更新 Version；已发布版本不可覆盖。旧的 InvoiceParser 混合仓库仅保留迁移说明并归档。
